# 제작 가이드 — 《신탁이 남긴 수수께끼: 이차곡선의 탄생》

단일 HTML(Canvas 2D) 수학사 애니메이션. 목표 룩: **스튜디오 지브리풍 극장용 손그림 2D 애니메이션**
(페인트된 배경 + 셀 캐릭터, 선의 떨림(boil), 12fps 홀드, 필름 그레인). 러닝타임 4:32 (272 s).

파일 구조 (모두 `conic-history/` 기준)
- `src/engine.js` — 공용 엔진 (아래 API). **API 시그니처를 바꾸지 말 것.** 버그 수정/추가는 허용.
- `src/script.js` — 자막·내레이션 타임라인(전역 초). `ANIM.TIMES`에 장면 시간표. **자막 문구/시간은 여기서만** 관리.
- `src/paint.js` — 배경 페인팅 라이브러리 `ANIM.paint.*`
- `src/chars.js` — 캐릭터/소품 라이브러리 `ANIM.chars.*`
- `src/scenes/s01.js … s07.js` — 장면 모듈 (각 파일이 `ANIM.scene({...})` 1회 호출)
- `dev.html` — 개발용(소스 분리 로드). `index.html` — `node tools/build.js`로 생성되는 **최종 단일 파일**.
- `tools/shoot.js` — 스크린샷/성능 측정. `shots/`는 git 무시.

## 장면 계약 (scene contract)
```js
ANIM.scene({
  id: 's03', title: '수학자들이 마주한 난제',
  start: 80, end: 120,            // 전역 초. 반드시 ANIM.TIMES[id] 와 동일
  mood: 'math',                   // 'ancient'|'oracle'|'work'|'math'|'rise'|'finale'|'silent' 또는 (t)=>mood
  fadeIn: 0.9, fadeOut: 0.9,      // 검정 페이드(초). 컷 전환이면 0
  init(api, S) { /* 1회. 배경 등 무거운 것은 여기서 u.layer()로 오프스크린에 미리 그려 S에 저장 */ },
  draw(api, t, S) { /* 매 프레임. t = 장면 로컬 초 (0 ~ end-start) */ },
});
```
`api` 필드: `ctx`(1920×1080 메인 컨텍스트), `W,H`, `u`(유틸), `t`(로컬 초), `T`(전역 초), `tq`(12fps 양자화 t), `frame`(12fps 프레임 번호), `boil`(8fps 번호 → 선 떨림 시드), `p`(0..1 진행), `seg(a,b)`(t 기준 0..1 진행), `cam({x,y,zoom,rot,shake})`/`endCam()`(화면 중심 기준 카메라 변환), `state`(=S).
- 엔진이 장면 뒤에 **그레인·비네트·자막**을 자동으로 올린다. 장면은 1920×1080 전체를 칠해야 한다(검정 배경 금지).
- 자막은 `script.js`가 담당. 장면 안에서는 **수식·라벨·화면 중앙 문구**만 직접 그린다 (예: `모서리 길이 2배 → 부피 8배`, `타원`).
- 예외를 던지면 그 장면은 검정으로 나오니, `node tools/shoot.js`의 에러 출력을 항상 확인.

## 엔진 API 요약 (`const {u} = api`)
수치: `u.clamp, u.lerp, u.map(v,a,b,c,d), u.smooth(a,b,x), u.seg(t,a,b), u.ease.{io,ioc,out,outc,outq,in,inc,sine,outBack}`, `u.frame(t,fps)`, `u.tq(t,fps)`, `u.boil(t)`, `u.rng(seed)()`, `u.noise2(x,y)`, `u.snoise`, `u.fbm(x,y,oct)`.
색: `u.hsl(h,s,l,a)`, `u.rgba`, `u.alpha('#hex',a)`, `u.mixHex(h1,h2,t)`, `u.grad(ctx,x0,y0,x1,y1,[[0,'#..'],[1,'#..']])`.
기하: `u.ellipsePts(cx,cy,rx,ry,n,rot,a0,a1)`, `u.circlePts`, `u.rectPts`, `u.curve(ctrlPts,segs,closed)`(Catmull-Rom), `u.resample(pts,step)`, `u.wobble(pts,jitter,seed)`, `u.polyPath(ctx,pts,closed)`.
**손그림 선/칠** (핵심):
- `u.ink(ctx, pts, {w, color, jitter, seed, alpha, closed, taper, step})` — 굵기 변하는 잉크 리본. **seed에 `api.boil`(+고유 오프셋)을 넣어 선이 8fps로 끓게** 한다.
- `u.sketch(ctx, pts, {passes,w,jitter,seed,alpha})` — 연필 멀티패스.
- `u.shape(ctx, pts, {fill, stroke, w, jitter, seed, alpha})` — 셀 칠 + 외곽선.
- `u.wash(ctx, pts, color, {seed,passes,spread,alpha})` — 수채 번짐 칠.
- `u.dab(ctx,x,y,r,color,alpha)`, `u.brush(ctx,x0,y0,x1,y1,{w,color,alpha,seed,scatter})` — 과슈 붓터치(배경용).
- `u.glow(ctx,x,y,r,color,alpha)`, `u.glowLine(ctx,pts,{color,w,halo,alpha,seed,closed})`(수학 발광 곡선), `u.ray(ctx,x0,y0,x1,y1,w0,w1,color,alpha)`(빛줄기).
- `u.paper(ctx,alpha,mode)` 종이/캔버스 질감(배경 레이어 마지막에), `u.grain`, `u.vignette`(엔진이 자동 적용).
- `u.layer(w,h,fn)` → 오프스크린 캔버스.
텍스트: `u.text(ctx,str,x,y,{size,font:'sans'|'serif'|'math',weight,italic,color,align,base,alpha,glow,glowColor,stroke,strokeW,spacing,maxWidth})`, `u.textW`, `u.math(ctx,'x³ = 2a³',x,y,{size,color,align,alpha,glow})`(라틴 문자는 이탤릭), `u.typed(str,p)`.
3D (카메라 궤도/투영, y가 위):
- `const P = u.camera({yaw,pitch,dist,fov,cx,cy,target})` → `P(x,y,z)` = `{x,y,z(깊이),s}`; `P.pts(arr3d)`.
- `u.cube(ctx,P,{origin:[x,y,z],size,color,edge,faceAlpha,w,jitter,seed,alpha,hiddenAlpha,glow})` 정육면체(반투명 면 + 보이는 모서리 발광/숨은 모서리 흐리게). `u.cubeFaces`, `u.cubeEdges`.
- 원뿔: 꼭짓점 `apex`(기본 원점), 축은 **−y 방향으로 열림**, 반꼭지각 `alpha`, 높이 `h`. `u.coneOutline(P,alpha,h,apex)` → `{outline, ring, sil, apex2d, farArc, nearArc}`(2D). `u.coneRing(alpha,y,n,apex)`(3D 원).
- `u.coneSection({alpha,h,double,plane:{p:[..],nrm:[..]},apex,n})` → 3D 점 브랜치 배열(**정확한 원뿔∩평면**; 쌍곡선은 `double:true`로 두 갈래). `u.conicType(alpha,nrm)` → 'circle'|'ellipse'|'parabola'|'hyperbola'. `u.planeBasis(plane)` → `{to2d,to3d}` 절단면을 2D로 펼칠 때.
오디오/음성은 엔진이 처리(`mood`만 지정). 참고로 `ANIM.snd.chime(freq)`, `ANIM.snd.sweep()`를 draw 안에서 1회성으로 호출 가능(상태 플래그로 중복 방지).

## 스타일 바이블 (반드시 지킬 것)
1. **배경은 '그린 그림'이어야 한다.** init에서 `u.layer`에 다층 붓터치(`u.brush`/`u.dab`/`u.wash`)로 하늘·바다·산·건물을 칠하고, `u.paper`로 질감을 얹는다. 균일한 단색 면·기본 선형 그라데이션만으로 끝내지 말 것. 하늘은 3~5단계 색 + 구름은 겹친 dab, 원경은 채도 낮게(대기 원근).
2. **선은 떨린다.** 모든 윤곽선은 `u.ink`/`u.sketch`로, seed에 `api.boil`을 섞는다. 굵기 2~4px(캐릭터), 1.5~2.5px(배경 디테일). 완벽한 원·직선 금지(`ctx.arc`/`lineTo` 직접 스트로크 금지).
3. **캐릭터는 12fps 홀드.** 포즈 전환은 `api.frame`/`api.tq` 기반 키프레임(2~4장 교대)로, 부드러운 소프트웨어 이징으로 관절을 돌리지 않는다. 걷기는 4프레임 사이클. 눈 깜빡임은 드물게(3~5초에 1회, 2프레임).
4. **카메라만 부드럽다.** 패닝/줌은 `api.cam`에 `u.ease.io` 등으로 천천히(장면당 1~2회). 멀티플레인: 원경·중경·근경 레이어를 서로 다른 속도로 이동(패럴랙스).
5. **색감.** 고대 장면: 새벽 금빛 `#f2c879`, 청동 `#b5762f`, 짙은 남색 `#1b2447`, 대리석 `#e8e1d3`, 그림자 보라 `#3b3558`, 에게해 `#2f6f9f`→`#5aa6c9`, 올리브 `#6f8a4e`. 수학 장면: 남색 `#0b1230`/`#121c45`, 청록 발광 `#58e0d0`, 금 발광 `#f3d27a`, 상아 `#f6f1e6`. 잉크색 `#2b1d14`(고대), `#9ff5ea`(수학).
6. **지브리적 디테일**: 바람에 흔들리는 풀/천, 떠다니는 먼지·빛 입자, 새 몇 마리, 구름 그림자, 빛줄기(`u.ray`), 촛불/횃불의 일렁임(boil 기반), 물결의 반짝임.
7. **금지**: 플라스틱 3D 음영, 완벽한 벡터 도형, 미끄러지는 레이어, 계속 바운스하는 요소, 인형 관절 회전, 과장된 표정, 코믹 연출, 빈 배경, 복붙된 나무 반복, 플레이스홀더.
8. **수학 그래픽**은 장식이 아닌 정확한 전달 수단: 비율·절단 위치·좌표를 검증. 수식은 `u.math` 벡터 텍스트로(이미지 아님). 고대 장면에 현대 좌표축/대수 기호를 넣지 않는다(S06만 예외, 자막으로 명시됨).
9. 텍스트 안전 영역: 자막 밴드가 y ≈ 1080−160 ~ 1080−40 을 차지 → 중요한 그림/수식은 y < 880 에 배치. 하단 왼쪽(캡션)도 비워 둔다.
10. 성능: `draw`는 24fps 기준 **≤ 25 ms**. 프레임마다 fbm 픽셀 루프 금지. 무거운 것은 init에서 레이어로.

## 테스트 방법
```
node tools/shoot.js --scene s03 --n 8 --out shots/s03 --sheet      # 장면 균등 8컷 + 컨택트시트
node tools/shoot.js --scene s03 --local 0.5,12,25,39 --out shots/s03  # 로컬 초 지정
node tools/shoot.js --scene s03 --play 6 --out shots/s03             # 6초 실시간 재생 fps 측정
node tools/build.js && node tools/shoot.js --file index.html --times 5,100 --out shots/final
```
스크린샷 PNG를 Read 도구로 직접 보고 자기 비평 → 수정 → 재촬영을 **최소 3회** 반복한다. (`shots/<scene>/sheet.png`)

## 장면 스토리보드 (전역 시간 · 자막은 script.js 참조)
### S01 신탁이 내려오다 — 0:00–0:40 · mood: t<18 'ancient', 이후 'oracle'
0–9 새벽의 에게해 전경: 황금빛 하늘, 푸른 바다, 섬(델로스)과 언덕 위 신전, 갈매기, 느린 줌인. 9–17 사람들: 불안에 떠는 섬 주민들(병든 이를 부축, 아이를 안은 어머니, 노인)이 신전으로 오르는 행렬, 횃불/연기. 17–31 신전 내부: 어둡고 신비, 대리석 기둥, 한 줄기 햇빛이 제단(정육면체)을 비춤, 사제들이 엎드림. 신탁 자막(19.5–30.6) 동안 빛이 고동치고 먼지 입자가 떠오름. 31–40 신탁이 끝나는 순간 정육면체 제단이 황금빛으로 빛나며 화면 중심으로(`u.glow`, 금빛 모서리). 캡션 자막은 엔진이 표시.
### S02 두 배로 만들었는데, 왜 실패했을까? — 0:40–1:20 · mood 'work' → 60초 이후 'math'
40–54 장인의 작업장(야외 채석장/작업대, 톱밥·돌가루 먼지, 망치질 홀드 애니메이션). 기존 정육면체 제단 옆에 2배 모서리의 큰 제단을 쌓는다. 장인들이 줄자(끈)로 모서리를 재는 컷(“2배”). 54–60 완성 순간 큰 제단이 반투명 3D 수학 모형으로 변환(crossfade): 작은 정육면체 `a`, `a³` 라벨, 큰 정육면체 `2a` 라벨. 60–66 큰 정육면체 내부가 작은 정육면체 8개로 분할되어 하나씩 채워지며(홀드 스텝) `8a³` 강조, 화면 중앙에 `모서리 길이 2배 → 부피 8배`. 66–69 정적(라벨만 남김). 69–80 질문 자막과 함께 두 정육면체가 나란히, 큰 것이 점차 희미해지고 ‘?’ 느낌의 빈 자리(원하는 2a³ 크기의 정육면체 실루엣이 점선으로 흐릿하게).
### S03 수학자들이 마주한 난제 — 1:20–2:00 · mood 'math'
80–97 고대 연구 공간(스토아/정원, 파피루스, 모래판에 도형을 그리는 수학자 2~3명, 기름등잔). 97–110 화면이 남색 수학 공간으로 전환: 정육면체 `a` 와 `x`; `x³ = 2a³` → `x = ∛2 × a` 가 천천히(타자기식) 나타남. 두 정육면체 나란히 비교, 모서리 비율 1.26 표시(`x ≈ 1.26a`), 부피가 정확히 2배임을 두 번째 정육면체 내부에 작은 정육면체 2개 분량의 ‘물’이 차오르는 식으로 직관적으로. 110–120 히포크라테스: `a : x = x : y = y : 2a` 비례식이 나타나고, 빛나는 선분 4개(a, x, y, 2a)로 변하며 다음 장면으로 흘러감(선분들이 화면 밖으로 흐르거나 모여듦).
### S04 메나이크모스의 새로운 발상 — 2:00–2:40 · mood 'ancient' → 150 이후 'rise'
120–134 기원전 4세기, 메나이크모스의 연구 공간(저녁, 등잔 불빛, 흰 수염 없는 중년 학자 상상 재구성, 키톤+히마티온). 모래판에 도형, 탁자 위 **나무/점토 원뿔 모형 2~3개(꼭지각이 다른)**. 그는 원뿔을 집어 들고 돌려보며 관찰. 134–150 원뿔 모형 클로즈업, 그의 손가락이 원뿔 표면을 따라가며 ‘잘린 면’을 상상하는 컷(손 위로 희미한 금빛 곡선 오버레이가 잠깐 떠오름 — 현대 좌표/기호는 없음). 150–160 그가 고개를 들고 창밖 별을 보는 컷, 원뿔 모형이 화면 중앙으로 떠오르며 반투명 청록으로 변하기 시작(다음 장면 연결).
### S05 원뿔 속에 숨겨진 곡선들 — 2:40–3:20 · mood 'rise'
반투명 청록 원뿔(`u.coneOutline` + 면 채움), 카메라 yaw 천천히 회전. 메나이크모스 방식 반영: **꼭지각이 다른 세 원뿔을 모선에 수직인 평면(옅은 금색)으로 자른다** — 예각 원뿔→타원, 직각 원뿔→포물선, 둔각 원뿔→쌍곡선(쌍곡선은 `double:true` 이중 원뿔로 두 갈래 표시). 각 절단: 평면이 미끄러져 들어오고(1.5 s) 교선이 `u.glowLine`으로 그려지며(1 s), 교선+평면이 화면 앞으로 이동·회전하여 정면 2D 곡선으로 펼쳐짐(`u.planeBasis`), 라벨(타원 / 포물선 / 쌍곡선, 한글 + 작은 설명 “닫힌 곡선”/“한 방향으로 무한히 뻗는 곡선”/“서로 분리된 두 갈래”). 타이밍: 170–179 타원, 179–188 포물선, 188–197 쌍곡선, 197–200 세 곡선 나란히. 단면 곡선과 평면 위 2D 곡선이 같은 대상임을 ‘붙어서 회전’으로 보여줄 것. 절단 평면/원뿔 수학은 `u.coneSection`으로 정확히.
### S06 두 곡선이 만나는 순간 — 3:20–4:00 · mood 'rise' → 226 이후 'finale'

## 역사·수학 정확성 체크리스트
- 신탁은 ‘전승’(확정 사실 아님) — 캡션 유지. 메나이크모스가 신탁 현장에 있었다는 묘사 금지(그는 기원전 4세기 인물).
- 메나이크모스 ≠ 아폴로니오스. 타원/포물선/쌍곡선 **명칭**은 아폴로니오스 이후 정착 → 메나이크모스 장면에서 그가 이름 붙였다고 암시하지 않기(라벨은 ‘학습자용 자막’ 톤).
- 고대 장면에 좌표축·대수 기호 금지(S06만 예외).
- 모서리 2배 → 부피 8배(8개 소정육면체), `x³ = 2a³`, `x = ∛2·a ≈ 1.26a`, 비례식 `a : x = x : y = y : 2a`(히포크라테스), 두 포물선 `x² = ay`, `y² = 2ax`의 교점 x = ∛2·a.
- 원뿔 절단면이 실제로 성립하는 평면이어야 하며(계산 기반), 쌍곡선은 두 갈래.
